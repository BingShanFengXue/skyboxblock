# 天空盒方块 R36 指令手册（`/skyboxblock`）

适用构建：**`skyboxblock-1.0.4-test.2-r36`**。
适用对象：**原版天空盒方块**（ID `skyboxblock:sky_block`，显示名「天空盒方块（原版）」）——它显示的是**本模组在私有画布上重画的原版风格天空**，不是世界的真实天空。
本文所有内容以**实际源码**（`server.SkyboxServerCommands`、`server.SkyboxServerConfig`、`SkyEnvironment`、`SkyTimeClock`）为准；实机验收计数见文末。

> **R36 起配置改为服务端权威**：属性与方块私有时间只保存**一份**（服务端 world 级），改动**对所有玩家同步生效**；
> 每个玩家看到的是同一套设置。变更需要**权限等级 2（OP）**，查询对所有玩家开放。

> 属性 ID、类型与默认语义参照 Minecraft 的**环境属性**体系（资料为社区 Wiki，非官方一手原文），但本模组是 1.21.1 上的**自研私有画布近似实现**，没有数据包那套修饰符链 / 时间线 / 插值。

---

## 1. 命令总览

```mcfunction
/skyboxblock                                   # 简短用法（无状态变化）
/skyboxblock environment                       # 与 list 相同
/skyboxblock environment list                  # 15 项属性各一行：visual/x = 值 | auto
/skyboxblock environment get <属性>             # 一行：visual/x = 值 | auto
/skyboxblock environment set <属性> <值>        # 保存并同步给所有玩家（OP2）
/skyboxblock environment set <属性> auto       # 等同 reset <属性>
/skyboxblock environment <属性>                # 等同 get <属性>（任何人可查）
/skyboxblock environment <属性> <值>            # 等同 set（OP2）
/skyboxblock environment <属性> reset          # 等同 reset <属性>（OP2）
/skyboxblock environment reset <属性>           # 单项恢复 auto（OP2）
/skyboxblock environment reset all             # 15 项全部 auto + 私有时间恢复 auto（OP2）
/skyboxblock environment reload                # 重读服务端配置（OP2）
/skyboxblock environment time …                # 私有天空时间，见 §5

/skyboxblock env …                             # env 与 environment 完全等价
```

### 1.1 权限

| 命令 | 谁可以用 |
|---|---|
| `list`、`get <属性>`、`<属性>`（仅查询）、`time`、`time get`、裸 `/skyboxblock` | **所有玩家** |
| `set …`、`<属性> <值>`、`reset …`、`<属性> reset`、`reset all`、`reload`、`time set/lock/unlock/reset` | **权限等级 2**（OP） |

权限不足时命令**不会执行**，也不会写入任何状态。纯查询不修改任何共享状态。

### 1.2 TAB 补全

**TAB 只给一种写法**：空或短名前缀 → 短 ID（`cloud_height`）；已输入 `visual/` → `visual/cloud_height`；已输入 `minecraft:visual/` → `minecraft:visual/cloud_height`。三种写法都能手动输入并执行，但补全列表里同一属性只出现一次，`list` 也只列一次。

```mcfunction
/skyboxblock environment set sky_color #7ba4ff
/skyboxblock environment set visual/sky_color #7ba4ff
/skyboxblock environment set minecraft:visual/sky_color #7ba4ff
```

属性 ID 沿用 `minecraft:` 命名空间；**不支持** `skyboxblock:` 命名空间，也不会把 `/` 换成下划线。

> **为什么补全只有一份**：命令树里只有**一个** `<attribute>` 参数节点（原版资源位置类型），建议由服务端按当前输入前缀生成。
> 这样专服把命令树同步给客户端时补全不会丢失、也不会出现 45 条重复项——客户端实际看到的就是上面这一套形式。
> 值参数是原版"整段字符串"，由执行体严格校验（颜色 `#RRGGBB` / `#AARRGGBB`、距离 `> 0`、亮度 `0..1`、八月相、`true`/`false`，以及 `auto`）；
> 多余 token、`NaN`、越界都在**写入前**被拒绝。

### 1.4 已移除的旧命令（R36）

根目录下的 `cloudheight`、`clouddistance`、`cloudfade` 与根 `reload` **已删除**，现在输入会直接解析失败（不执行、不改服务端配置）。替代写法：

| 旧命令（已移除） | 现在这样写 | 说明 |
|---|---|---|
| `/skyboxblock cloudheight 240` | `/skyboxblock env set cloud_height 240.33` | 旧命令是**名义**高度，环境属性是**最终**高度，差 0.33 |
| `/skyboxblock cloudheight reset` | `/skyboxblock env reset cloud_height` | 回退到旧键 `vanillaCloudHeight` |
| `/skyboxblock clouddistance 768` | `/skyboxblock env set cloud_fog_end_distance 768` | 数值原样相同 |
| `/skyboxblock cloudfade 100 400` | `/skyboxblock env set fog_start_distance 100` + `/skyboxblock env set cloud_fog_end_distance 400` | 见下 |
| `/skyboxblock reload` | `/skyboxblock env reload` | 重读服务端配置 |

⚠ **`fog_start_distance` 是天空与云共用的雾起点**，不是"只改云"。设它同时改变方块内天空雾的起点和云的淡出起点——这是本模组的真实行为，不要当成仅限云的开关。
⚠ 只设 `cloud_fog_end_distance` 而不设 `fog_start_distance` 时，云的淡出起点沿用旧规则（旧键 `vanillaCloudFadeStart`，默认 128），只有**显式**设了 `fog_start_distance` 才由它决定。

### 1.5 `cloud_height` 与 0.33

原版云几何在名义高度上加 `+0.33`，所以旧 `/skyboxblock cloudheight 192` 的云实际在 **y ≈ 192.33**。环境属性 `cloud_height` 是**最终高度**，不再加偏移：

| 写法 | 云实际高度 |
|---|---|
| 旧 `cloudheight 192`（已移除） | 192.33 |
| `env set cloud_height 192.33` | **192.33**（与上一行相同） |
| `env set cloud_height 240` | 240.00 |

## 2. `auto` 与旧配置回退

每个属性默认 `auto`：不覆盖，走本模组原本的算法。**15 项全部 auto 时，画面与升级前完全一致。**

- `env reset <属性>` / `env set <属性> auto` 删除该属性覆盖（服务端统一记录）。删除后 `cloud_height`、`cloud_fog_end_distance` 会回落到**旧配置键**（`vanillaCloudHeight`、`vanillaCloudFadeEnd`）——旧键**继续被读取**，既不迁移也不删除。
- `env reset all` 只清 `environment.*` 覆盖与**私有天空时间设置**；旧云层键与其他配置项原样保留。
- 查询只显示**明确写下的覆盖值**：没有覆盖就是 `auto`，**不会把旧键算出来的数值当成"当前值"报给你**。旧键回退的语义就是这一节。

⚠ 我们的 `auto` ≠ 原版默认值，三处不同：`cloud_color`（auto 有云且不透明）、`cloud_fog_end_distance`（auto 跟旧键 384，原版 2048）、`has_sky_occluder`（auto 按 1.21.1 原生高度条件）。

## 3. 属性清单（15 项）

颜色写法**只有一种**：`#` + 十六进制。RGB 为 `#RRGGBB`（6 位），ARGB 为 `#AARRGGBB`（8 位，保留 alpha 与符号位），大小写不限、保存时统一大写。

```mcfunction
/skyboxblock env set sky_color #00FFFF
/skyboxblock env set cloud_color #8000FFFF
/skyboxblock env set sunrise_sunset_color #FFFF8040
```

**不接受**其他写法：`0x00FFFF`、`0xFFFFFF00`、不带 `#` 的 `00FFFF`、三位缩写 `#0FF`、颜色名（`red`）都会被拒绝并提示正确写法；位数不对（RGB 少于或多于 6 位、ARGB 少于或多于 8 位）同样拒绝，且**不修改服务端配置**。R35 曾接受 `0x` 前缀，R36 起统一为 `#`；旧配置文件里残留的 `0x…` 值读取时按无效处理并回落到 `auto`，用 `env set` 重写为 `#…` 即可。
距离类必须 **> 0**（0 与负数被拒绝）。角度类为有限度数，`0 = 正上方`。

| 属性（可省略 `visual/`） | 类型 | 原版默认 | 范围 / 说明 |
|---|---|---|---|
| `sky_color` | RGB | `#000000` | 天空本体颜色 |
| `fog_color` | RGB | `#000000` | 雾色，也是画布底色与地平线颜色 |
| `fog_start_distance` | float | `0.0` | 天空雾**与云淡出共用**的起点，可为负 |
| `fog_end_distance` | float | `1024.0` | 天空雾结束距离，> 0；实际生效值不低于 96 |
| `sky_fog_end_distance` | float | `512.0` | 天空雾独立结束距离，> 0；未设时回退用 `fog_end_distance` |
| `cloud_color` | ARGB | `#00000000` | 云色与不透明度，alpha=0 即不画云 |
| `cloud_height` | float | `192.33` | **最终**世界 Y（旧命令名义值 + 0.33） |
| `cloud_fog_end_distance` | float | `2048.0` | 云淡出结束距离，> 0，上限 4096（沿用旧云距性能上限） |
| `sunrise_sunset_color` | ARGB | `#00000000` | 霞光色与强度，alpha=0 不画；覆盖后不随时间衰减 |
| `sun_angle` | float 度 | `0.0` | 太阳角度 |
| `moon_angle` | float 度 | `0.0` | 月亮角度，独立于太阳 |
| `star_angle` | float 度 | `0.0` | 星空角度，独立于日月 |
| `moon_phase` | 枚举 | `full_moon` | 八月相名或 `0`–`7` |
| `star_brightness` | float | `0.0` | 0–1；显式设置后不再被雨/雷暴压暗 |
| `has_sky_occluder` | 布尔 | 主世界 `true` | `true` / `false`；auto 沿用 1.21.1 原生高度条件 |

月相序号：0 `full_moon` 满 · 1 `waning_gibbous` 亏凸 · 2 `third_quarter` 下弦 · 3 `waning_crescent` 残 · 4 `new_moon` 新月 · 5 `waxing_crescent` 峨眉 · 6 `first_quarter` 上弦 · 7 `waxing_gibbous` 盈凸。

## 4. 常用复制命令

```mcfunction
# 永久正午
/skyboxblock env set sun_angle 0
/skyboxblock env set moon_angle 180
/skyboxblock env set star_brightness 0

# 紫罗兰黄昏
/skyboxblock env set sky_color #4b2a72
/skyboxblock env set fog_color #7a4b8f
/skyboxblock env set sunrise_sunset_color #c048ff90
/skyboxblock env set sun_angle 75

# 无云、星星亮的夜空
/skyboxblock env set cloud_color #00000000
/skyboxblock env set moon_phase new_moon
/skyboxblock env set star_brightness 1
/skyboxblock env set sky_color #050510

# 云拉高到最终 Y=240，并让云从 100 格开始淡出到 320 格
/skyboxblock env set cloud_height 240
/skyboxblock env set fog_start_distance 100
/skyboxblock env set cloud_fog_end_distance 320

# 只看半个天空（关掉下半球遮挡）
/skyboxblock env set has_sky_occluder false

# 全部还原（15 项 + 时间）
/skyboxblock env reset all
```

## 5. 方块内部时间（服务端统一、不影响世界）

这些设置只改变**方块画布里的天空时刻**，**不会**改变世界的 `time`、天气或任何世界状态；只写进本模组的私有天空时间设置，由服务端统一保存并同步给所有玩家。

```mcfunction
/skyboxblock env time                 # 查询当前设置（一行，任何人可查）
/skyboxblock env time get             # 同上
/skyboxblock env time set <ticks|preset>       # 设为该时刻（OP2）：未锁定时从此走时；已锁定时只改锁定值、保持锁定
/skyboxblock env time lock            # 锁定当前时刻（画面静止，OP2）
/skyboxblock env time lock <ticks|preset>      # 锁定到指定时刻（OP2）
/skyboxblock env time unlock          # 从锁定时刻继续走时（OP2）
/skyboxblock env time reset           # 回到跟随默认策略（auto，OP2）
```

- `ticks`：整数 `0..23999`（一天 = 24000 tick）。
- `preset`：`day`=1000、`noon`=6000、`night`=13000、`midnight`=18000、`sunrise`=0、`sunset`=12000。
- 例：`/skyboxblock env time set noon` → 方块内固定从正午开始走时；`/skyboxblock env time lock sunset` → 永久停在日落。
- **`set` 不改动锁定状态**：已经 `time lock` 之后再执行 `time set midnight`，结果仍是 `locked`，只是锁定值变成 18000；想要重新走时请显式 `time unlock`。反过来，从 `auto` 或 `running` 执行 `set` 会进入 `running` 并从该时刻计时。
- 设置、锁定与走时锚点保存在**服务端**并持久化；重新进入世界从保存的起点开始，**不计离线时间流逝**，锁定值同样持久。
- `env reset all` 会把私有时间一并恢复 auto（**只重置时间不会清掉那 15 项属性**，反之亦然）。
- **显式角度/颜色覆盖优先**：若你设了 `sun_angle` / `moon_angle` / `star_angle` / `sky_color` 等，固定或改变时间时这些值仍按你设的走，**时间的视觉效果可能不明显**——这是"覆盖即最终值"的必然结果，不是时间没生效。

## 6. 服务端配置与同步

配置由**服务端 world 保存**（`<世界存档>/serverconfig/skyboxblock.properties`），客户端只负责展示，因此：

- 一个世界一份设置，**所有玩家看到的一致**；OP 改完立刻广播给在线玩家。
- 客户端**不读**本地 `-Dskyboxblock.environment.*`，也不会把"本地保存"当生效值——命令显示的就是服务端当前的共享设置。
- 手改服务端配置文件后，用 `/skyboxblock environment reload`（OP2）让服务端重新读取。
- 键名格式（服务端配置文件）：

```properties
# 覆盖项：键前缀固定 environment.，属性为 auto 时不写这一行
environment.visual/sky_color=#7BA4FF
environment.visual/cloud_height=240.33
environment.visual/moon_phase=waxing_gibbous
```

同一属性的多个键写法（`environment.visual/<属性>`、`environment.<短ID>`、`environment.minecraft:visual/<属性>`）以 canonical `visual/...` 为准；旧键 `vanillaCloudHeight` / `vanillaCloudFadeStart` / `vanillaCloudFadeEnd` 继续作为 auto 回退读取，不删除。

## 7. 范围与限制

1. **只影响原版天空盒方块**；另外 8 种材质天空盒不受影响。
2. **不影响真实世界**：维度天空、世界雾、光照、天气、世界时间一律不动。
3. **覆盖即最终值**：颜色/亮度显式设置后不再被天气或时间衰减。
4. **没有修饰符链、没有插值、没有时间轴**：设什么就是什么，切换立即发生。
5. **移植近似**：`has_sky_occluder` 用"雾色 + 渐隐下半球"近似原版 26.4，方向一致但不保证逐像素相同；`sunrise_sunset_color` 未实现"下半天空被霞光填充"。
6. **不提供的属性**：`sky_light_color` / `sky_light_factor`、`block_light_tint`、`night_vision_color`、`ambient_light_color`、`audio/*`、`gameplay/*`、水下雾三项——它们改的是整个世界的光照/音频/玩法/水下近景，违反"绝不动世界"的原则。本模组**完全不触碰**你的真实水下雾。
7. **日月星不吃雾**（与原版一致）。
